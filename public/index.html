Put UBERS tracking in your Roblox game

Drop the tracker script into ServerScriptService, set the token, and your vehicles appear on this site live.

1. Server

npm install
cp .env.example .env   # add your keys
npm start              # http://localhost:3000

2. Roblox Studio

Copy roblox/UBERS_VehicleTracker.server.lua into ServerScriptService and set TRACKING_TOKEN to the same value as your .env.

3. Your token

hidden

The token never leaves the server - only the health of the link is shown here.
