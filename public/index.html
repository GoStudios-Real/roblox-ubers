npm install

Roblox servers cannot reach your PC's localhost. Deploy this server at a public HTTPS URL, set BASE_URL in the Roblox script, and allow outbound HTTP in Roblox Studio.

2. Roblox Studio

Only install this script in an experience you own. Copy roblox/UBERS_VehicleTracker.server.lua into ServerScriptService, set the same TRACKING_TOKEN, and configure MAP_ID and the playable world bounds.

3. Anonymous positions

hidden

Player names and account IDs are not shown. Reports expire after 20 seconds; set the player's UBERS_TrackingOptOut attribute to true to exclude them.

4. Owner-installed driver scripts

Copy roblox/UBERS_Dispatch.server.lua into ServerScriptService in an original experience you own or are authorized to integrate, including your own test place. Configure the server URL/token/map and world bounds, and add your own car, taxi and bus models under ServerStorage/UBERSVehicles. Place a depot marker named UBERSDepot in Workspace, then load a Profile Games profile whose public games include your published place so bookings, stats, and dispatch use its place ID, and adapt the POIs/routes to your world. Routes use straight-line sample movement and require adaptation/testing. This cannot add drivers to or modify the official Brookhaven RP or Welcome to Bloxburg games — real human drivers claim those rides on the Drive tab instead.

HELP & HOW-TO

Frequently asked questions

Quick answers about bookings, real human drivers, live game information, and how this service works.

Are these real rides or real vehicles?

Real drivers, in-game rides. Every ride is claimed by a real human player who drives you to your stop inside a Roblox game. UBERS matches riders and drivers on this website; it does not arrange real-world transportation or dispatch vehicles outside Roblox.

Can UBERS put a driver in any Roblox game?

Real human drivers work in any game — they join with their own account and drive you in-game. Only each experience's creator can publish server scripts, so automated driver scripts run only in experiences where the creator installs the UBERS dispatch script.

Can bots spawn cars, buses or taxis to drive me in Brookhaven RP?

No, and you should never trust sites that claim otherwise. Making a bot drive inside someone else's game requires a script executor (a hack client), which violates Roblox's terms, gets accounts permanently banned, and often carries malware. Roblox gives outside tools no legal way to run code in a third-party game. That's why UBERS uses real human drivers: players claim your booking on the Drive tab and pick you up in-game, or a game's own creator installs the UBERS dispatch script for automated vehicles in experiences they own.

How do Drive jobs work?

Open the Drive tab to see open bookings. Claim one with a display name and your Roblox username, and you get a private driver code (saved only in your browser). Join the Roblox game with the join button, meet the rider at the pickup stop with a car, taxi or bus, and use the status buttons — On the way, At pickup, Picked up, Completed. The rider's booking page updates every 15 seconds automatically, so their Ride tracking bar shows your progress in real time.

Can the driver and rider end up in different Brookhaven servers?

Yes — public Roblox APIs don't let a website place two specific players into one server. Both sides should agree on the same public server from the Roblox API tab's server list (or use a private server link), then meet at the pickup stop. UBERS passes the game, route, stop and time so both sides know exactly where to meet.

How do I book and manage a ride?

Choose Book a ride, select a game, route, stops, departure and seats, then enter a display name. You can attach a public Roblox username, but it is not verified sign-in. Save the booking reference and private management key. Use both under My bookings to view or cancel it.

Why can't I see players on the map?

Roblox's public APIs provide aggregate game and public-server information, not player identities or in-world positions. Anonymous position dots only appear for a Roblox experience whose owner has installed and configured this project's tracker.

Are seat times and capacity real-time?

Seat availability updates from bookings stored on the connected UBERS server. The timetable is a schedule, not a live vehicle estimate; check the Drive tab to see which rides a real human driver has claimed.

What if the website says bookings aren't connected?

GitHub Pages is static. Timetables, booking storage, and cancellation need the UBERS Node server and its HTTPS API tunnel to be online. The Windows app runs the server locally; a Cloudflare Quick Tunnel only works while its connector is running and its address can change.

What information do you need?

A short display name, selected stops, departure, and number of seats are stored on the server to manage the booking. Do not enter passwords, email addresses, phone numbers, or other sensitive personal information. Public timetable responses never list rider names or booking references.

How do I contact the game creators?

ROBLOX UBERS is GoStudios Of Roblox Transport. For game-specific help, please use the official support channels of the games you play.

By using ROBLOX UBERS, you agree to these terms. ROBLOX UBERS is operated by GoStudios Of Roblox Transport — real human drivers for Roblox.

1. In-game ride service

ROBLOX UBERS provides maps, game information, ride timetables, and reservations for rides driven by real human players inside Roblox games. It is not a real-world taxi, rideshare, transport, emergency, or dispatch service. No real-world journey, vehicle, pickup, safety screening, or arrival time is promised or arranged. Do not rely on it for real-world travel or emergencies.

2. Bookings and acceptable use

Bookings reserve in-game seats only, subject to available capacity on the connected server. Schedules are illustrative and may change or be unavailable. You are responsible for keeping your booking reference and private management key secure. Anyone with that key may view or cancel its booking. Do not submit real names, contact details, passwords, or sensitive personal information as a display name.

Drive jobs match volunteer drivers with riders for in-game rides. When you claim a job you see the rider's display name, departure, stops, and — if the rider attached one — their public Roblox username; never private account data. When you attach a Roblox profile to a ride, volunteer drivers offering a lift can see that public username. Drivers act independently: UBERS does not employ, verify, background-check, or supervise drivers, assigns no real pickup, and promises no arrival. A driver code is a private bearer credential like the management key — keep it secret; anyone holding it can update that ride's status. Both riders and drivers must follow the host game's rules and Roblox's terms; do not use exploits or scripts in games you do not own.

3. Data and privacy

Booking details (display name, game, route, stops, departure, seats, status, and creation time) are stored in the operator's local app-data folder or the server's configured data directory so the booking can be managed. They are not shown in public timetable listings. The management key is returned at booking time, its hash is stored on the server, and the browser saves the key in local storage for your itinerary. Driver codes work the same way: the code is shown once, only its hash is stored, and the browser keeps it in local storage to list your claimed jobs. Clear this site's browser storage to remove the locally saved keys. The operator should secure and delete server booking data when no longer needed. This service does not provide a user account or promise a particular retention period.

Live player position reports are available only from experiences where the owner installed the tracker; reports use anonymous identifiers, expire after 20 seconds, and respect the experience's tracking opt-out. Other live game information is sourced from public Roblox APIs. The website may make requests to Roblox, Cloudflare, GitHub Pages, OpenRouter, or Stripe integrations when enabled; those providers apply their own terms and privacy policies.
