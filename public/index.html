Connect app to live UBERS server

Set the HTTPS address of your live UBERS server. This lets the mobile app connect without rebuilding when a tunnel address changes. Only connect to a server you trust.

1. Public server

npm install
cp .env.example .env   # add your keys
npm start              # http://localhost:3000

Roblox servers cannot reach your PC's localhost. Deploy this server at a public HTTPS URL, set BASE_URL in the Roblox script, and allow outbound HTTP in Roblox Studio.

2. Roblox Studio

Only install this script in an experience you own. Copy roblox/UBERS_VehicleTracker.server.lua into ServerScriptService, set the same TRACKING_TOKEN, and configure MAP_ID and the playable world bounds.

3. Anonymous positions

hidden

Player names and account IDs are not shown. Reports expire after 20 seconds; set the player's UBERS_TrackingOptOut attribute to true to exclude them.

4. Owner-installed NPC rides

Copy roblox/UBERS_Dispatch.server.lua into ServerScriptService in an original experience you own or are authorized to integrate, including your own Brookhaven-style or Bloxburg-inspired test place. Configure the server URL/token/map and world bounds, and add your own NPC-equipped car, taxi and bus models under ServerStorage/UBERSVehicles. Place a depot marker named UBERSDepot in Workspace, set the matching ROBLOX_UBERS_PLACE_ID_* in the server .env, and adapt the POIs/routes to your world. A ride can board only after the Roblox account linked to the booking joins that same server. Routes use straight-line sample movement and require adaptation/testing. This cannot add bots to or modify the official Brookhaven RP or Welcome to Bloxburg games.

Frequently asked questions

Quick answers about roleplay bookings, live game information, and how this fan project works.

Are these real rides or real vehicles?

No. UBERS is a fan-made Roblox roleplay dashboard. Reservations are fictional schedules for in-game play and do not arrange transportation, hire drivers, or dispatch real vehicles.

Can UBERS put a driver in Brookhaven or Bloxburg?

No. These are third-party Roblox experiences. Only each experience's creator can publish server scripts there. UBERS can dispatch owner-provided NPC vehicles in an experience where you have creator access and install the dispatch script.

How do I book and manage a ride?

Choose Book a ride, select a game, route, stops, departure and seats, then enter a roleplay display name. You can attach a public Roblox username, but it is not verified sign-in. Save the booking reference and private management key. Use both under My bookings to view or cancel it.

Why can't I see players on the map?

Roblox's public APIs provide aggregate game and public-server information, not player identities or in-world positions. Anonymous position dots only appear for a Roblox experience whose owner has installed and configured this project's tracker.

Are seat times and capacity real-time?

Seat availability updates from bookings stored on the connected UBERS server. The timetable is a roleplay schedule, not a live vehicle estimate; it doesn't guarantee a player or vehicle will be present in the game.

What if the website says bookings aren't connected?

GitHub Pages is static. Timetables, booking storage, and cancellation need the UBERS Node server and its HTTPS API tunnel to be online. The Windows app runs the server locally; a Cloudflare Quick Tunnel only works while its connector is running and its address can change.

What information do you need?

A short roleplay display name, selected stops, departure, and number of seats are stored on the server to manage the booking. Do not enter passwords, email addresses, phone numbers, or other sensitive personal information. Public timetable responses never list rider names or booking references.

How do I contact the game creators?

ROBLOX UBERS is not affiliated with, endorsed by, or sponsored by Roblox Corporation or the creators of Brookhaven RP or Welcome to Bloxburg. Please use their official support channels for game-specific help.
