Put UBERS tracking in your Roblox game

Install the server script in an experience you own to send anonymous live player positions and vehicle locations to a public UBERS server. Roblox's public game API does not expose in-world player positions.

1. Public server

npm install
cp .env.example .env   # add your keys
npm start              # http://localhost:3000

Roblox servers cannot reach your PC's localhost. Deploy this server at a public HTTPS URL, set BASE_URL in the Roblox script, and allow outbound HTTP in Roblox Studio.

2. Roblox Studio

Only install this script in an experience you own. Copy roblox/UBERS_VehicleTracker.server.lua into ServerScriptService, set the same TRACKING_TOKEN, and configure MAP_ID and the playable world bounds.

3. Anonymous positions

hidden

Player names and account IDs are not shown. Reports expire after 20 seconds; set the player's UBERS_TrackingOptOut attribute to true to exclude them.

Endpoints

GET/api/tracking?map=brookhavenLive vehicle positions
POST/api/tracking/pingRoblox place reports vehicles (x-ubers-token)
GET/api/players?map=brookhavenAnonymous, recent player positions
POST/api/players/pingRoblox server reports its player roster (x-ubers-token)
GET/api/roblox/games?placeIds=...Roblox game stats + icons
POST/api/ai/chatOpenRouter AI support
POST/api/billing/checkoutStripe checkout session
POST/api/wifi/connectFree WiFi access code
